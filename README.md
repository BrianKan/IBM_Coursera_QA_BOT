# IBM_Coursera_QA_Bot

**QABot** is a Python project that lets you ask natural language questions about datasets or databases and get answers powered by large language models (LLMs) like IBM's Watson AI.

## Features

- Ask questions about your PDF using plain English
- Supports Watson AI via Gradio or compatible services
- Easy setup and friendly web interface

## Installation

You can install QAB


Or install from your cloned repository:

git clone https://github.com/yourusername/qabot.git
cd qabot
pip install .
